远程呼唤
小爱音箱趣味互动插件 · Remote Caller

向家中的小爱音箱远程发送本尊原音或小爱 TTS 播报，让传统音箱秒变「家庭对讲机」和「整蛊神器」🚀

🎮 趣味应用场景
📻 家庭对讲机
跨房间赛博喊话，吃饭叫人不用扯嗓子
⏰ 夺命连环 Call
音量拉满原音咆哮，专治早上赖床不起
👻 搞怪整蛊
深夜小爱 TTS 悄悄传话，制造科技惊喜
🐱 远程逗宠
出门在外原声呼唤主子，围观歪头杀
✨ 核心特性
📱 PWA 独立应用：Material Design 3 现代风格，支持添加到手机桌面独立运行，自动适配白天 / 黑夜模式。
🎙️ 双模延迟发送：自由切换本人原音与小爱语音，支持松手后 1~10 秒延迟自动发送（可随时取消）及原音试听。
💬 实时对话记录：气泡实时显示对方呼叫小爱的内容，完整留存双方对话记录，随时翻看互动详情。
🛡️ 贴心安全防线：音量超过 80% 触发二次预警防惊吓，内置 HTTPS 录音环境检测与友好防呆提示。
